# Recurring visit planner — selectable on-screen reviewed note (PR #220)

## Goal
LMS #218 added **Copy reviewed visit** and #219 added a single-date
**Download reviewed visit TXT** alternative. Both export the same
three-line, date-only text with explicit **NOT BOOKED** warnings.
On some phone browsers, clipboard APIs or local file downloads may
be unavailable. This change lets users inspect, select and manually
copy that same proposed-only note straight from the Schedule screen
without requiring either browser API.

## Behavior
- Inside the existing **Reviewed proposed visit details** panel,
  alongside **Copy reviewed visit**, **Download reviewed visit TXT**,
  and **Prepare this visit manually**, show a native
  **Preview visit note** toggle. It starts collapsed.
- Clicking the toggle renders a **read-only, selectable text area**
  labelled **Selectable proposed visit note — NOT BOOKED**.
  Its text is generated by the exact same
  `recurringVisitReviewedText(startDate, everyWeeks, occurrences,
  selectedDate)` function already used for clipboard and TXT.
  The helper strictly revalidates the selected date's membership in
  the current 1/2/4-week, 2–12-date calendar proposal.
- The note shows **only** the selected visit's ordinal position,
  weekday, business-local YYYY-MM-DD date, and clear NOT BOOKED /
  no-resources-confirmed warnings. It includes no saved appointment
  counts, customer names, organization details, work, resource,
  location, money or appointment times.
- The toggle changes to **Hide visit note** while expanded; clicking
  it closes the text area. The native button has `aria-expanded`
  and the text box has a stable accessible label and `readOnly`.
  The text area is not editable and its content is not saved.
- Selecting a different proposed visit via the existing dropdown,
  per-card Review, or First/Previous/Next/Last buttons closes the
  old note; opening Preview again shows the newly selected date.
  Changing the recurrence interval, proposed-visit count, or
  business-local calendar anchor actively closes the note. Reverting
  those controls to their previous values does not reopen a formerly
  displayed note; the operator must explicitly click Preview again.
- If the agenda date is not part of the valid current proposal,
  or the preview is invalid/overflowed, the entire focused-visit
  panel (and note toggle) is absent as before.
- The feature stays available in **Compact view**, where the
  numbered cards are hidden. It neither re-anchors a proposal nor
  changes the selected agenda date.
- A plain explanatory line invites manual selection/long-press
  when browser clipboard or download access is restricted.
  Clipboard failure messaging now recommends either TXT download
  **or Preview visit note**. No automatic copy occurs.
- Existing manual one-date preparation, Save/Cancel return,
  24-demo-session cap and ordinary Schedule navigation are unchanged.

## Accessibility and responsive design
- Native `button` with `aria-expanded` for an explicit,
  keyboard-operable toggle; no inactive/off-screen keyboard targets.
- Native `textarea readOnly` with a readable accessible label;
  text can be selected by mouse, keyboard or touch.
- Theme-based high-contrast `--text`, `--surface-alt`,
  `--border` styling in light and dark themes; 100% width
  with `min-width: 0`, comfortable padding and responsive
  word wrapping in the existing selected-visit panel.
- No extra `<details>` element is nested inside the planner:
  existing Schedule resume semantics and Playwright selectors remain
  unchanged.

## Privacy and safety
The note is created on demand from the existing validated,
business-local **unsaved** recurrence preview. It never examines
saved records, makes a server request, accesses clipboard/storage,
creates a booking, assigns a resource, checks availability,
sends a message, or persists anything. No new API, schema,
migration, permission, payment, automatic recurrence or
organization boundary changes. ForgeOS and other repos untouched.

## Regression tests
Extend the existing no-login Cleaning Company and Property Manager
Playwright scheduling sessions (no new demo sessions):
- First-of-four preview is initially hidden, toggle is accessible,
  read-only note equals the exact three-line unbooked text, and
  Hide removes it.
- After selecting date #3 in a six-date plan, the on-screen note
  equals the already tested clipboard and TXT payload verbatim,
  and excludes saved-status/customer/work/resource information.
- Clipboard denial keeps the selectable note available and
  offers TXT/preview as fallbacks, without a false copy success.
- Off-plan and overflowing plans hide the note and its toggle;
  restoring a valid plan keeps the preview collapsed by default.
- Regression for the initial Browser failure: after an open note,
  change the recurrence interval to exclude the selected agenda date,
  then restore the old interval. Verify no note reappears. Open
  the note again, change from six to twelve visits, verify it closes,
  and open only on deliberate click.
- Open a reviewed note, change the calendar anchor to an invalid
  overflowing date, then restore the previous anchor. The note
  remains closed; the user must choose Preview again.
- In twelve-date Compact view the preview is usable; selecting
  date #10 closes the previous text and reopening shows #10,
  with the correct current agenda date.
- Preserve existing browser tests for unit-tested date rules,
  CSV/full-plan copy, exact TXT bytes, WCAG/mobile fitting,
  manual single booking Save/Cancel and saved-record snapshots.
